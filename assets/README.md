# `assets/` (Zasoby Statyczne)

* **Status:** ⚪ `[OPCJONALNY]`

Katalog przeznaczony na statyczne pliki multimedialne i binarne (grafiki, audio, modele 3D, fonty, pliki do druku/PnP).
Stosowany, gdy aplikacja wymaga plików binarnych nielogicznych. W przeciwnym razie może zostać pominięty.
