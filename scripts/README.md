# `scripts/` (Automatyzacja)

* **Status:** ⚪ `[OPCJONALNY]`

Katalog przeznaczony na skrypty pomocnicze, migracje bazy, deployment i automatyzację CI (Node.js, bash, Python).

---

### Relacja `scripts/` vs `tools/`
- **Domyślny standard:** W projektach webowych, hybrydowych i ogólnego przeznaczenia stosujemy katalog **`scripts/`**.
- **Alternatywa dla stacku natywnego:** W projektach niskopoziomowych (C++, Rust) oficjalny standard dopuszcza użycie katalogu **`tools/`** (np. na wewnętrzne kompilatory, telemetrię, generatory kodu C++) zamiast lub obok folderu `scripts/`.
